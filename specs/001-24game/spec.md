# Feature Specification: 24点计算网页游戏

**Feature Branch**: `001-24game`
**Created**: 2026-04-22
**Status**: Draft
**Input**: User description: "开发一个计算24点的网页游戏"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 经典模式完成一道24点题 (Priority: P1)

**描述**: 儿童玩家在经典模式中，看到4张数字卡片，用运算符卡片拼成一个正确算式得出24点

**为何这个优先级**: 这是游戏的核心玩法，必须首先实现

**独立测试方式**: 可以单独测试这个场景 - 输入4张卡片和算式，验证是否等于24

**接受场景**:

1. **Given** 系统显示4张数字卡片 `[3, 8, 3, 8]`, **When** 玩家选择卡片 `[3, 8, 3, 8]` 和运算符 `[+, ×, ÷, -]` 拼接成 `8÷(3-8÷3)=24`, **Then** 系统显示正确反馈和星级评价

2. **Given** 系统显示4张数字卡片 `[1, 2, 3, 4]`, **When** 玩家拼接算式 `(1+2+3)×4=24`, **Then** 系统显示正确并给出星级

3. **Given** 系统显示4张数字卡片 `[1, 1, 1, 1]`, **When** 玩家宣布"这组无解", **Then** 系统验证后确认确实无解，显示正确反馈

4. **Given** 系统显示4张数字卡片 `[5, 5, 5, 1]`, **When** 玩家选择换牌, **Then** 系统换成一组新的数字卡片

---

### User Story 2 - 竞速模式挑战 (Priority: P2)

**描述**: 儿童玩家在竞速模式中，60秒内尽可能多地解答24点题目

**为何这个优先级**: 竞速模式是第二个核心玩法，增加游戏多样性

**独立测试方式**: 可以单独测试 - 启动倒计时，验证计分和超时处理

**接受场景**:

1. **Given** 玩家进入竞速模式, **When** 计时开始60秒, **Then** 倒计时显示并逐秒递减

2. **Given** 玩家在30秒时答对一道题, **When** 系统判定正确, **Then** 玩家获得基于时间的分数加成

3. **Given** 玩家在60秒倒计时结束, **When** 还有未完成的题目, **Then** 游戏结束，显示本轮总成绩

---

### User Story 3 - 提示系统使用 (Priority: P3)

**描述**: 玩家遇到困难时使用提示功能，每局限制使用3次

**为何这个优先级**: 提示是儿童友好体验的重要组成，帮助学习

**独立测试方式**: 可以单独测试 - 验证提示次数限制和提示内容显示

**接受场景**:

1. **Given** 玩家本局已使用2次提示, **When** 玩家再次点击提示按钮, **Then** 系统显示剩余1次提示

2. **Given** 玩家本局已使用3次提示, **When** 玩家再次点击提示按钮, **Then** 系统显示"提示已用完"

3. **Given** 玩家点击提示, **When** 系统显示提示信息, **Then** 提示包含部分算式线索但不直接给出答案

---

### Edge Cases

- 玩家使用除法时除数为0应该如何处理
- 玩家输入不完整算式（如只有数字没有运算符）时如何反馈
- 连续多次输入错误时是否需要调整难度或给予更多鼓励
- 无解牌组时玩家选择"宣布无解"但实际有解的情况如何处理

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须随机生成4张1-13的数字卡片
- **FR-002**: 系统必须提供加减乘除四种运算符卡片供玩家选择
- **FR-003**: 玩家必须能够通过拖拽或点击将数字和运算符卡片拼接到算式区
- **FR-004**: 系统必须验证玩家算式是否正确等于24点
- **FR-005**: 系统必须在答对时显示动画、音效和文字鼓励（如"太棒了！"）
- **FR-006**: 系统必须在答错时显示正确答案
- **FR-007**: 系统必须在玩家宣布无解时验证是否确实无解
- **FR-008**: 系统必须提供换牌功能，玩家可主动更换当前牌组
- **FR-009**: 系统必须提供有限次数提示，每局3次
- **FR-010**: 系统必须根据正确性和速度综合评定1-3星
- **FR-011**: 竞速模式必须提供60秒倒计时
- **FR-012**: 经典模式每轮必须包含10组牌
- **FR-013**: 系统必须默认开启音效
- **FR-014**: 游戏数据仅保存在当前会话，关闭标签页后丢失

### Key Entities

- **数字卡片**: 包含1-13的数字，具有选中/未选中状态
- **运算符卡片**: 包含加、减、乘、除四种运算符
- **牌组**: 4张数字卡片的组合，用于一道题目
- **算式**: 玩家拼接的数字和运算符的表达式
- **游戏状态**: 当前模式、得分、星级、提示次数剩余等
- **计时器**: 竞速模式的倒计时功能

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 儿童玩家能够在5分钟内完成一局经典模式（10组牌）
- **SC-002**: 90%的正确算式能在100ms内得到验证反馈
- **SC-003**: 100%的无解牌组能被系统正确识别
- **SC-004**: 竞速模式在60秒倒计时结束后正确结束游戏
- **SC-005**: 提示功能在3次用完后正确禁用

## Assumptions

- 目标设备为现代浏览器（Chrome, Firefox, Safari, Edge最新两个版本）
- 玩家具备基本的算术运算知识（加减乘除）
- 游戏主要在平板或电脑上运行，手机端作为可选支持
- 无需联网即可完成核心游戏功能
